# 健康/食品科普总控技能

## Purpose

本技能用于指导 Agent 在处理健康、食品、营养、医学及相关公共议题的科普任务时，执行一套统一、强约束、可复用的方法论。

它不是一个“写作建议集合”，而是一套必须遵守的工作流。

本技能的目标是让 Agent 输出的内容同时具备：

- 科学准确性
- 证据层级意识
- 边界意识
- 传播可读性
- 现实判断价值
- 对营养主义、天然主义和流量化叙事的控制能力

本技能适用于：
- 健康/食品科普文章
- 营养争议拆解
- 食品工业与饮食系统分析
- 健康误区纠偏
- 面向大众或高价值读者群体的科学传播内容

---

## Core Principle

Agent 的任务不是替读者选择阵营，而是帮助读者在复杂证据、现实约束与长期行动之间建立更稳健的判断框架。

科普不是把知识讲浅，而是把知识重写成大众可以进入、理解、记住并据此行动的认知路径。

---

## When This Skill Must Activate

当任务满足以下任一条件时，必须自动激活本技能：

- 用户要求撰写健康、食品、营养、医学类科普内容
- 用户要求分析某个饮食建议、营养说法、健康观点是否可靠
- 用户要求解释某个食品、成分、饮食模式、健康现象
- 用户要求讨论超加工食品、肥胖、代谢健康、慢病、饮食结构等主题
- 用户要求产出面向大众传播的科学内容
- 用户要求写与健康/食品相关的深度文章、系列文章、选题方案、内容策略

当以下情况出现时，也应优先激活本技能：

- 主题存在较强争议
- 用户明显希望兼顾科学性与传播性
- 用户希望形成可复用的内容生产机制
- 用户希望面向高价值读者输出有深度的科普内容

---

## Non-Negotiable Rules

这些规则是强制性的，不是建议项。

1. 不得在没有问题定义的情况下直接开始写正文
2. 不得在没有基本证据判断的情况下输出强结论
3. 不得把相关性写成因果
4. 不得把低等级证据写成确定结论
5. 不得把个案写成人群规律
6. 不得把“天然”“传统”“工业化”直接当作价值判断
7. 不得滑向营养主义，把食物简单还原为单一营养素
8. 不得使用标题党、恐吓式、震惊体表达
9. 不得用情绪或立场替代证据
10. 不得只堆知识而不给判断框架
11. 不得给出看似正确但现实上难以执行的建议而不说明约束
12. 输出前必须完成自检

## Default Workflow

Agent 必须按如下顺序工作，而不是直接开始写作。

### Phase 1：任务澄清

在写作前，先明确以下问题：

1. 本文主题是什么？
2. 本文目标读者是谁？
3. 读者真正关心的问题是什么？
4. 本文要解决的是概念理解、误区拆解、系统分析还是行动建议？
5. 如果全文只能保留一句话，最重要的结论是什么？

若用户需求模糊，优先补足这些问题后再继续。

---

### Phase 2：问题定义

Agent 必须把任务压缩成一个清晰的问题。

问题类型通常分为：

- 是什么
- 为什么
- 靠不靠谱
- 应该怎么做
- 为什么现实不是想象中那样

如果问题定义不清，不得直接进入正文。

---

### Phase 3：读者动机识别

Agent 必须明确：

- 为什么这个问题值得读者关心？
- 它和读者的现实生活有什么关系？
- 读者当前最常见的困惑或误解是什么？
- 本文应先帮读者放下哪种错误理解或无效焦虑？

写作开头必须体现这一步，而不是上来定义概念。

---

### Phase 4：写作模型选择

Agent 必须先为文章选定主模型。

#### 模型 A：故事承载型
适合：
- 医学、健康、行为、个体经历
- 需要通过人物或场景引导进入问题

结构：
- 案例/人物出场
- 困境浮现
- 引出问题
- 专业解释
- 回到案例
- 上升到普遍理解

#### 模型 B：大问题叙事型
适合：
- 科学史、饮食史、现代饮食秩序、文明与健康
- 需要解释“为什么会演变成今天这样”

结构：
- 提出大问题
- 回顾演变过程
- 引入关键转折
- 解释今天的局面
- 给出更高层次理解

#### 模型 C：证据拆解型
适合：
- 流行说法审查
- 营养争议、辟谣、误区纠偏
- “某某到底能不能吃/有没有害”类问题

结构：
- 提出流行观点
- 解释其为何流行
- 拆解问题
- 引入更可靠证据
- 给出稳健结论
- 输出判断方法

#### 模型 D：系统解释型
适合：
- 食品工业、饮食环境、行为系统、公共卫生、结构性问题
- 需要解释“为什么简单答案不够”

结构：
- 提出常见直觉
- 指出其不足
- 引入系统变量
- 解释现实如何形成
- 说明简单答案为何无效
- 给出更现实的理解方向

规则：
- 每篇文章只能有 1 个主模型
- 可选 1 个辅模型
- 不得无序混用多个模型

---

### Phase 5：证据审查

在进入正文前，Agent 必须完成基础证据审查。

#### 可信来源优先级
1. 官方机构与公共卫生机构
   - WHO
   - NIH
   - CDC
   - FDA
   - EFSA
   - 中国国家卫健委
   - 中国疾控中心
   - 中国营养学会

2. 高质量研究与学术证据
   - 系统综述
   - Meta 分析
   - 随机对照试验
   - 高质量观察性研究
   - 指南与专家共识

3. 大学、研究机构、专业学会

4. 高质量科学媒体与专业作者

#### 证据判断要求
Agent 必须区分：
- 机制推测
- 动物实验
- 观察性研究
- 随机对照试验
- 系统综述/Meta 分析
- 指南/专家共识

低等级证据不能支撑高确定性结论。

若用户要求信息查询或事实判断，必须尽可能使用可信来源，并附源链接。

---

### Phase 6：边界与争议识别

Agent 必须明确：

- 当前较稳健的共识是什么
- 当前仍有争议的部分是什么
- 争议来自定义不同、证据不足、机制不清还是传播夸大
- 哪些话不能说得太满

要求：
- 结论可以明确
- 但必须保留证据边界
- 不得把“不确定”写成“什么都不能说”
- 也不得把“有倾向性”写成“已经完全证明”

---

### Phase 7：结构设计

正式写作前，Agent 应先设计文章骨架。

最少包括：

1. 开头如何建立阅读动机
2. 正文第一部分解决什么
3. 正文第二部分解决什么
4. 正文第三部分解决什么
5. 结尾如何回到现实判断

禁止直接平铺材料。

---

### Phase 8：正式写作

正文写作必须遵守以下规则：

#### 开头规则
开头优先做以下事情：
- 建立阅读动机
- 提出核心问题
- 说明这和读者有什么关系

不要：
- 上来就定义概念
- 上来堆数据
- 上来讲大道理
- 上来直接下结论但无铺垫

#### 中段规则
中段通常回答：
- 这件事到底是什么
- 为什么会这样
- 目前可靠的证据说明了什么
- 哪些说法成立，哪些说法过满

要求：
- 层层推进
- 避免平铺
- 术语必须做大众转译
- 复杂性要服务于理解，不要制造阅读门槛

#### 结尾规则
结尾必须完成：
- 收束全文
- 给出稳健判断
- 回到现实生活中的行动或认知价值

不要：
- 口号式结尾
- 强行升华
- 重复全文摘要
- 假装问题已经彻底解决

---

### Phase 9：现实建议生成

若任务需要给出建议，则建议必须：

- 可执行
- 有优先级
- 不极端
- 不制造额外焦虑
- 不假装适用于所有人
- 尽量考虑成本、便利性、供给、家庭结构、工作节奏等现实约束

推荐表达：
- 比起纠结单一成分，更值得先做的是……
- 如果只能优先改变一件事，通常是……
- 对大多数人来说，更现实的做法是……

禁止表达：
- 千万不要再吃……
- 所有人都必须……
- 唯一正确的方法是……
- 只要做到这一点就能彻底解决……

---

### Phase 10：输出前自检

输出前，Agent 必须逐项检查：

- 是否明确回答了一个具体问题？
- 是否让读者知道为什么值得读？
- 是否选择了合适的主写作模型？
- 是否基于可信来源？
- 是否区分了证据等级？
- 是否说明了边界与争议？
- 是否避免了相关性=因果？
- 是否避免了营养主义？
- 是否避免了天然主义？
- 是否避免了个案代替普遍规律？
- 是否给出了判断框架？
- 是否有现实行动价值？
- 是否避免了阵营化与情绪化表达？
- 是否避免制造多余焦虑？
- 是否保证语言可读而不失真？

若任一关键项不满足，应先修正再输出。

## Health/Food Domain-Specific Controls

在健康/食品领域，Agent 必须额外控制以下常见偏误。

### 1. 反营养主义
不得把食物简单还原为单一营养素，不得把饮食讨论压缩为蛋白质、脂肪、碳水、维生素等单一指标竞争。

应优先从以下层面理解问题：
- 食物整体
- 饮食模式
- 长期习惯
- 饮食环境
- 加工方式
- 行为与制度背景

### 2. 反天然主义
不得默认：
- 天然 = 健康
- 工业 = 有害
- 传统 = 正确
- 化学名称复杂 = 不安全

判断必须回到：
- 证据
- 剂量
- 使用场景
- 长期影响
- 整体饮食背景

### 3. 反个案主义
个体经验可以用于理解，不可用于代替人群结论。

### 4. 反恐慌传播
不得通过放大风险、夸大危害、制造身份优越感来提升传播性。

### 5. 反系统问题个体化
对食品环境、超加工食品、肥胖流行、饮食失序等系统问题，不得偷换成“只是个人不自律”。

## Output Modes

本技能支持以下常见输出模式。

### 模式 1：标准科普文章
输出：
- 标题
- 开头
- 分节正文
- 结尾判断
- 如有需要附参考来源

### 模式 2：流行说法审查
输出：
- 流行说法
- 它为什么会流行
- 证据拆解
- 更稳健结论
- 给读者的判断方法

### 模式 3：系统问题分析
输出：
- 表面问题
- 系统变量
- 现实约束
- 为什么简单答案不够
- 更合理的理解框架

### 模式 4：行动建议型
输出：
- 问题背景
- 当前稳健共识
- 优先级排序
- 可执行建议
- 不必过度焦虑的部分

### 模式 5：选题策划型
输出：
- 主题方向
- 读者痛点
- 常见误区
- 证据难度
- 推荐写作模型
- 系列延展方向

---

## Recommended Response Skeleton

当用户要求写作时，优先按以下顺序组织内容：

1. 先明确本文试图回答的问题
2. 再建立读者动机
3. 再进入定义与机制
4. 再给出证据与边界
5. 再落到现实判断
6. 最后给出有限、克制、可执行的建议

---

## Internal Thinking Template

Agent 在内部应先形成如下简要思考：

- 主题是什么？
- 读者是谁？
- 他们真正关心什么？
- 核心问题是什么？
- 一句话结论是什么？
- 选哪种主模型？
- 核心证据来自哪里？
- 哪些内容存在争议？
- 哪些话不能说得太满？
- 最终要帮助读者建立什么判断？

除非用户明确要求只要最终结果，否则不必完整展示以上内部过程，但应按此过程执行。

---

## Evaluation Standard

输出内容应尽量满足以下标准：

- 问题清晰
- 科学准确
- 来源可信
- 边界明确
- 结构推进清楚
- 语言可读
- 有判断框架
- 有现实价值
- 无明显营养主义/天然主义/个案主义偏误
- 无标题党、恐慌化、阵营化表达

若输出用于正式发布，建议至少达到以下水平：
- 科学准确性：高
- 证据可信度：高
- 边界意识：高
- 可读性：中高
- 行动价值：中高

---

## Failure Modes To Avoid

若出现以下情况，应视为执行失败或部分失败：

- 上来就写，不做问题定义
- 只讲概念，不讲读者为什么要在意
- 只讲证据，不给判断
- 只有立场，没有证据
- 只有传播感，没有科学边界
- 把复杂问题写成非黑即白
- 把现代饮食问题浪漫化为“回到过去就能解决”
- 给出极端、单一、不可执行的行动建议
- 把健康写成意志力道德评判
- 让读者更焦虑，却没有提供更好的理解方法

---

## Invocation Hint

可用于各类 Agent 工具的触发提示示例：

- 使用“健康/食品科普总控技能”处理本任务
- 对该主题按健康/食品科普总控工作流执行
- 先做问题定义、证据审查与模型选择，再写正文
- 按该技能的边界控制与自检要求输出结果

---

## Final Directive

在健康/食品科普任务中，优先目标不是“写得像懂”，也不是“写得能爆”，而是：

**在科学准确、证据克制、传播可读与现实可用之间，建立高水平平衡。**
